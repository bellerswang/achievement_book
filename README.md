# 成就本 Achievement Book

May 的成就本 —— 运动模块 v1。纯数值、成长曲线为主角的手机网页应用（PWA），数据只存在本机（IndexedDB）。

## 运行

```bash
npm install
npm run dev      # 本地开发 http://localhost:5173
npm test         # vitest 单元测试（派生指标 + 曲线几何）
npm run build    # 打包到 dist/
npm run preview  # 预览打包结果
```

手机上用 Safari 打开后「添加到主屏幕」即可像 App 一样使用。

### 演示数据（开发开关）

开发模式（`npm run dev`）或在网址后加 `?dev`（如 `http://localhost:4173/?dev`）时，
首页右上角 👪 家长区里会出现 **🛠 演示数据（开发）**：「载入演示数据」会清空现有记录并生成约 75 天的示例数据，
演示数据都带 `demo` 标记，家长区的「清除演示数据」一键只删演示数据。正式使用时不带 `?dev` 就看不到「载入」入口。

## 结构

| 文件 | 作用 |
| --- | --- |
| `src/presets.js` | 预置运动（拉单杠三关 / 跑步按米 / 跳绳默认隐藏）及指标定义 |
| `src/metrics.js` | 纯函数派生指标：个人最佳、累计、连续天数、7 点移动平均、较上月、今天尝试次数等（不落库） |
| `src/db.js` | IndexedDB（`idb`）：`exercises`、`entries` 两个 store；设置存 localStorage |
| `src/chart.js` | 手写 SVG 成长曲线与迷你 sparkline（无图表库） |
| `src/celebrate.js` | 新纪录庆祝动画（星星 / 闪光 / 彩纸）+ 轻震动，不依赖声音 |
| `src/main.js` | 首页（两个大入口）、运动贴纸本页、记录弹层、家长区 |
| `src/backup.js` | 备份导出 / 导入、公里→米迁移（纯函数） |
| `src/illustrations.js` | 引体高度示意图（SVG） |
| `src/seed.js` | 演示数据生成 |

## 设计约定（v3 极简版）

- 首页只有两个大入口：🧗 拉单杠、🏃 跑步。跳绳的代码和数据都保留，默认隐藏，可在家长区打开。
- 每个运动一页「贴纸本」，每页只放：（单杠）成长路 / （跑步）距离选择 → 一个大数字 → 一张曲线 → 贴纸，底部一个「记录」大按钮。
- 曲线只显示进步：画到目前为止的最好成绩（阶梯线），永远不会往下走。
- 拉单杠分三关：抓杠（每次固定尝试 N 下，记「3/5」）→ 悬挂（当天最长秒数）→ 引体向上（May 点 25/50/75/100% 的图，家长可在「家长：输入精确 %」里填 0–100）。下一关达到门槛才出现。
- 跑步按「米」：100/200/400/600/800/1000 米或自定义，记录用时（分/秒）和可选圈数；每个距离单独比较，更快时显示「快了 N 秒」，更慢不显示差距。
- 旧版本以公里存的跑步记录会在升级时自动换算成米（IndexedDB v2 迁移，导入旧备份时也会换算）。
- 白底、粗黑边框、单一主色 `#0B3D91`，没有浅色底和渐变；状态不只靠颜色（✓ / 📍 / ▲ + 文字）；字号用 rem 跟随系统缩放；尊重「减少动态效果」。
- 家长区（首页右上角 👪 小按钮）：单杠门槛、庆祝效果、语言、显示跳绳、导出 / 导入备份（JSON）、一键清除演示数据、清空全部、管理（删除）记录。
- GitHub Pages 打包：`npm run build:pages`（base 为 `/achievement_book/`）。
